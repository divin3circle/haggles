## HTTP Wire Headers

| Header | Direction | Format |
|---|---|---|
| `WWW-Authenticate` | Seller → Buyer (`402`) | `Haggles challenge="<base64url(JSON)>"` |
| `Haggles-Challenge` | Seller → Buyer (`402`) | `<base64url(JSON)>` |
| `Haggles-Payment` | Buyer → Seller (Retry) | Compact Ed25519 JWS (`typ: "haggles-pay+jwt"`) |
| `Haggles-Receipt` | Seller → Buyer (`2xx`) | Compact Ed25519 JWS (`typ: "haggles-receipt+jwt"`) |

## URL Canonicalization Rules (`SPEC.md` § 4.3)

1. Lowercase scheme (`http` or `https`) and lowercase ASCII/punycode host.
2. Strip default port (`:80` for `http`, `:443` for `https`).
3. Strip URL `#fragment`.
4. Normalize empty path to `/`.
5. Sort query parameters lexicographically by UTF-8 key, then value.
