## Adapters

- `import { paywall } from "@haggles/server/hono"` — Hono middleware factory.
- `import { paywall } from "@haggles/server/express"` — Express 4/5 middleware factory.
- `import { createPaywallCore } from "@haggles/server"` — Framework-agnostic HTTP 402 challenge & redeem engine.
